# European Space Infrastructure Companies

A curated, filterable directory and map of European space infrastructure companies, with a focus on startups.
Live at https://companies.svenamberg.com

It covers: launch providers · spaceports · rideshare and in-space transport · satellite and bus builders ·
ground stations · mission control and software · tracking and space safety · propulsion

Edit `scripts/build_data.py`, then run `python scripts/build_data.py`. Suggestions are welcome as issues.
